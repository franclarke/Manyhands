# 06 — El protocolo longitudinal dice lo que el driver hace

**What to build:** el protocolo pre-registrado declara el executor que realmente se usa y la consecuencia de esa eleccion, en vez de contradecir a su propio driver.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Declara el executor real y su consecuencia: tokens como piso y costo no medible.
- [ ] La reversion queda declarada en el protocolo, no solo en un comentario del codigo.
- [ ] Una prueba falla si la seleccion del protocolo y la del driver divergen.
