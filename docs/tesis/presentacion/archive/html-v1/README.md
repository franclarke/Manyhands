# Presentación HTML v1 — archivo histórico

Este directorio preserva dos exploraciones HTML tempranas de la defensa. Son
antecedentes de diseño, no la presentación oral vigente ni la fuente del PPTX
final de 15 diapositivas.

- `index.html`: deck HTML autónomo de **22 diapositivas**.
- `Main.dc.html`: artboard de Claude Design Canvas de **14 diapositivas**.
- `canvas.json`: layout y entrypoint del Design Canvas.
- `support.js`: runtime mínimo para abrir `Main.dc.html` en un navegador común.
- `manyhands-defensa-tesis.html`: export publicado que encapsula el estado
  editable del Design Canvas y su metadata.

Para una inspección local sencilla puede servirse el directorio con un servidor
HTTP estático y abrir `index.html` o `Main.dc.html`. Las fuentes tipográficas de
estas versiones se solicitan a Google Fonts, por lo que una apertura totalmente
offline puede usar fallbacks locales.

El deck vigente y su fuente reproducible se encuentran en:

- [`../../ManyHands-presentacion-oral.pptx`](../../ManyHands-presentacion-oral.pptx)
- [`../../source/`](../../source/)
- [`../../guion-presentacion-oral.md`](../../guion-presentacion-oral.md)

Las diferencias de cantidad, narrativa y evidencia entre estas versiones son
intencionales: HTML v1 documenta la evolución del diseño y no debe usarse para
atribuir resultados actuales.
