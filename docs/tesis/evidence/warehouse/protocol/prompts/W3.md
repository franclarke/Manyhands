# W3 — Órdenes y reservas visibles

## Goal

Incorporá ingreso de órdenes, reserva atómica de stock y estados visibles en el
control tower, incluidos rechazos explicables por stock insuficiente.

## Acceptance

- Una orden válida reserva stock sin cambiar el total físico; una inválida no
  deja reservas parciales.
- Estados `received`, `reserved`, `picking`, `completed` y `rejected` tienen
  transiciones validadas y texto visible.
- La sonda W3 agrega `orders` con casos aceptados/rechazados y confirma
  conservación de reservas; preserva W1–W2.
- Tests incluyen concurrencia o doble reserva y todos los gates pasan.

## Probe contract

El comando `pnpm study:probe -- --increment W3 --scenario thesis-seed-2026 --format json`
escribe en stdout un único objeto JSON y ninguna otra salida, con exactamente
esta forma:

```json
{
  "schemaVersion": 1,
  "increment": "W3",
  "scenario": "thesis-seed-2026",
  "stateHash": "sha256:0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef",
  "capabilities": {
    "layout": {
      "zones": 4,
      "bins": 16
    },
    "inventory": {
      "skus": 5,
      "totalUnits": 240
    },
    "visual": {
      "svgElements": 64,
      "heatmapCells": 16,
      "textLabels": 12
    },
    "orders": {
      "accepted": 3,
      "rejected": 1,
      "reservationConserved": true
    }
  }
}
```

La envoltura fija `schemaVersion`, `increment` y `scenario`. Las capacidades
requeridas en este incremento son `layout`, `inventory`, `visual`, `orders`.
Cada una vive anidada dentro de `capabilities`: ninguna se publica en el nivel
superior ni se renombra.

Los valores del ejemplo son ilustrativos. Derivalos del escenario respetando
estos mínimos e invariantes, que el oráculo externo verifica:

- `layout.zones` es un número >= 3.
- `layout.bins` es un número >= 12.
- `inventory.skus` es un número >= 3.
- `inventory.totalUnits` es un número >= 1.
- `visual.svgElements` es un número >= 1.
- `visual.heatmapCells` es un número >= 12.
- `visual.textLabels` es un número >= 3.
- `orders.accepted` es un número >= 1.
- `orders.rejected` es un número >= 1.
- `orders.reservationConserved` es exactamente `true`.

`stateHash` es la cadena `sha256:` seguida de 64 dígitos hexadecimales
minúsculos. Dos invocaciones sobre el mismo commit emiten bytes idénticos.

## Constraints

- Base: verified delivery of W2.
- Las reglas viven fuera de componentes UI e infraestructura. La sonda usa las
  mismas operaciones productivas y el escenario fijado.

## Oracle

Oracle id: `warehouse-w3-v1`. Verifica layout, inventario, visual y órdenes.
