# W2 — Primer control tower visual

## Goal

Agregá una aplicación web que represente el layout W1 como plano SVG y el stock
como heatmap comprensible, con leyenda, etiquetas textuales y detalle de bin.

## Acceptance

- El plano renderiza zonas, pasillos y al menos una celda por bin del escenario.
- Ocupación y stock crítico no dependen sólo del color; hay labels y leyenda.
- La selección de un bin muestra SKU, cantidad, capacidad y estado.
- La sonda W2 productiva agrega `visual` con conteos de SVG, heatmap y labels,
  preservando capacidades W1; test, typecheck y build pasan.

## Probe contract

El comando `pnpm study:probe -- --increment W2 --scenario thesis-seed-2026 --format json`
escribe en stdout un único objeto JSON y ninguna otra salida, con exactamente
esta forma:

```json
{
  "schemaVersion": 1,
  "increment": "W2",
  "scenario": "thesis-seed-2026",
  "stateHash": "sha256:0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef",
  "capabilities": {
    "layout": {
      "zones": 4,
      "bins": 16
    },
    "inventory": {
      "skus": 5,
      "totalUnits": 240
    },
    "visual": {
      "svgElements": 64,
      "heatmapCells": 16,
      "textLabels": 12
    }
  }
}
```

La envoltura fija `schemaVersion`, `increment` y `scenario`. Las capacidades
requeridas en este incremento son `layout`, `inventory`, `visual`.
Cada una vive anidada dentro de `capabilities`: ninguna se publica en el nivel
superior ni se renombra.

Los valores del ejemplo son ilustrativos. Derivalos del escenario respetando
estos mínimos e invariantes, que el oráculo externo verifica:

- `layout.zones` es un número >= 3.
- `layout.bins` es un número >= 12.
- `inventory.skus` es un número >= 3.
- `inventory.totalUnits` es un número >= 1.
- `visual.svgElements` es un número >= 1.
- `visual.heatmapCells` es un número >= 12.
- `visual.textLabels` es un número >= 3.

`stateHash` es la cadena `sha256:` seguida de 64 dígitos hexadecimales
minúsculos. Dos invocaciones sobre el mismo commit emiten bytes idénticos.

## Constraints

- Base: verified delivery of W1.
- UI React/Vite accesible y responsive; SVG es parte del producto, no una
  captura estática. No hardcodear el resultado de la sonda.

## Oracle

Oracle id: `warehouse-w2-v1`. Verifica capacidades acumulativas y observables
visuales mínimos desde el camino productivo.
