# W5 — Rutas de picking

## Goal

Calculá una ruta de picking válida para órdenes reservadas y superponela al
plano SVG con paradas numeradas, distancia y explicación de imposibilidad.

## Acceptance

- El algoritmo respeta conectividad y nunca atraviesa zonas no caminables.
- Para el escenario fijado produce al menos 2 paradas y distancia positiva; una
  ubicación aislada devuelve error tipado.
- La UI muestra overlay, orden de paradas y métricas legibles.
- La sonda W5 agrega `routing` con paradas, distancia y overlay visible;
  preserva W1–W4 y los gates pasan.

## Constraints

- Base: verified delivery of W4.
- Ruta y visualización comparten el mismo resultado productivo; no mantener una
  ruta paralela para la sonda.

## Oracle

Oracle id: `warehouse-w5-v1`. Verifica capacidades acumulativas y routing.
