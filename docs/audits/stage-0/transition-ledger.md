## Reading the ledger

The current-state labels are deliberately conservative:

- `foundation`: a useful mechanism exists and should be preserved, but it does
  not yet establish the target invariant;
- `partial`: part of the required semantics exists, with a material gap;
- `incompatible`: the productive route contains behavior the invariant
  explicitly forbids;
- `missing`: the target owner or representation does not exist.

`Stage / cutover / retire` records the first implementation stage, the stage at
which the target becomes productive, and the stage that removes the superseded
producer or authority. A range means that the invariant is introduced in one
stage and completed as downstream adapters become real. `mapped` in the G0
column means the baseline has named an owner, evidence, gap and disposition; it
does **not** mean the invariant currently passes.

The inspected worktree also contained Stage 0 harness, documentation and test
changes. Those are inventoried by the Stage 0 baseline record. None changes the
productive implementation evidence summarized here.
