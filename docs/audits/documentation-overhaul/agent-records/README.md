# Registros históricos de agentes

Este directorio conserva los informes, reviews, handoffs, planes y estados de
gate producidos durante el overhaul de documentación. Se retuvieron los
resultados sustantivos; briefings, dispatches, actualizaciones de progreso,
scripts ad hoc y otros archivos de coordinación regenerables quedaron fuera.

Son registros **históricos y no normativos**. Reflejan el conocimiento y el
estado percibido por cada agente en un momento concreto, y pueden contener
links, rutas, nombres o conclusiones luego superados. Un `PASS`, un handoff o
una ausencia de hallazgos en estos archivos no prueba por sí solo una capacidad
del producto.

La interpretación debe contrastarse con `PRODUCT.md`, el plan canónico de
rediseño, el código y las pruebas del snapshot exacto, y la evidencia posterior
atribuible. El valor de estos archivos es explicar cómo se llegó a una decisión
y permitir auditoría del proceso documental.
