# Historical Thesis/Evaluation Plan

> Status: superseded. This document used to describe a thesis and benchmark
> evaluation path. It is intentionally no longer an active plan.

The current repository direction is product-first. The previous strategy based
on deterministic Lab Mode, mock benchmark scenarios, B0-B4 baselines,
G3/G6/G9 granularity targets, and a fixed thesis experiment matrix has been
retired.

Future evaluation will be designed after the product is complete enough to
measure honestly. That future design may use public benchmarks or custom tasks,
but no methodology is implied by this archived plan.
