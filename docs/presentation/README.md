# Presentación del diseño objetivo

Esta carpeta contiene un relato de la **arquitectura objetivo**, no evidencia de
que todas sus capacidades estén implementadas. Antes de una presentación del
producto real, las afirmaciones deben contrastarse con la auditoría de transición
y un run observado.

- [`guion-exposicion.md`](guion-exposicion.md): relato para público general.
- [`evidencia-tecnica.md`](evidencia-tecnica.md): checklist de afirmaciones que
  requieren verificación.
- [`../design/golden-fixtures.md`](../design/golden-fixtures.md): recorrido de la
  demo principal.
