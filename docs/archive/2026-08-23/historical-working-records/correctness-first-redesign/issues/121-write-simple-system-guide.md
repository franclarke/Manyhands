# CF-121 — Write the accessible end-to-end system explanation

- **Status:** `ready-for-agent`
- **Blocked by:** CF-110

## Outcome

Explain in Spanish, for software engineers who are not specialists in agent
orchestration, how a goal becomes a plan, graph, execution, integrated candidate,
evidence, and delivery; how decisions and failures appear; and why the principal
architectural choices exist.

## Acceptance

- The guide follows one concrete, GProd-verified run and avoids unsupported
  implementation detail.
- Technical terms are defined once, complex mechanisms have plain-language
  explanations, and limitations remain explicit.
- Screenshots/diagrams bind to the exact verified candidate and visible UI path.
- A technical reviewer and a non-specialist reader can follow the complete flow.
