# CF-120 — Document the complete as-built architecture

- **Status:** `ready-for-agent`
- **Blocked by:** CF-110

## Outcome

Produce the technical system documentation from current source and GProd
evidence: module/dependency map, contracts, data flow, planning/granularity,
actors/effects/recovery, repository views/resources, attempts/Git artifacts,
validation/evidence, integration/repair, sandbox/security, delivery,
observability/cost, decisions, limitations, and rationale.

## Acceptance

- Every material claim links current code, deterministic test, gate evidence, or
  explicit inference/limitation.
- Target history is distinguished from implemented behavior.
- Public interfaces, failure modes, operational guarantees, residual trust, and
  rejected alternatives are explained without creating a second normative spec.
- Diagrams and links render and obsolete terminology/references are absent.
