# Registros históricos de trabajo

Este directorio conserva una copia de material local de trabajo que podía ser
útil para reconstruir el proceso de rediseño:

- `audit_report.md`, una auditoría histórica;
- `correctness-first-redesign/spec.md`, la especificación de trabajo de ese
  momento;
- `correctness-first-redesign/issues/`, el ledger local de tickets y gates.

El contenido es **histórico y no normativo**. Sus estados pueden haber quedado
desactualizados y sus links, comandos o rutas pueden retener el contexto local
original. No deben usarse por sí solos para afirmar que una capacidad existe,
que un stage cerró o que un candidato fue validado.

Para interpretar discrepancias, prevalecen `PRODUCT.md`, el plan canónico
`docs/plans/2026-08-12-correctness-first-system-redesign.md`, el código y las
pruebas del snapshot exacto, y la evidencia posterior atribuible. Este archivo
sirve para recuperación y trazabilidad de decisiones, no para sustituir esas
fuentes.
